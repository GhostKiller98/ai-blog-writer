# ✍️ AI Blog Writer

Turn a topic into a polished, **publish-ready Markdown blog post** — complete with a title, hook, structured sections, key takeaways, and a conclusion.

A small Node.js + Express web app with a clean, dark UI. Runs out of the box in **demo mode** (no API key needed), and switches to **live AI generation** the moment you add an `OPENAI_API_KEY`.

## Features

- **One-click generation** — type a topic, pick a tone and length, get a structured article.
- **Tone control** — Professional, Friendly, Witty, Inspirational, or Neutral.
- **Length control** — Short (~400 words), Medium (~850 words), or Long (~1600 words).
- **Preview + Markdown tabs** — read it rendered, or grab the raw Markdown.
- **Copy & download** — copy to clipboard or download a ready-to-publish `.md` file.
- **Demo mode by default** — works instantly with zero setup; plug in an API key for real AI output.

## Quick start

First install dependencies:

    npm install

Then (optional) enable live AI generation:

    export OPENAI_API_KEY="sk-..."

Finally run it:

    npm start

Open <http://localhost:3000>.

For development with auto-reload:

    npm run dev

## How it works

| Mode | When | What you get |
| --- | --- | --- |
| **Demo** | No `OPENAI_API_KEY` set | A polished, fully-realized sample article built from your topic |
| **Live AI** | `OPENAI_API_KEY` set | A fresh article generated by OpenAI (GPT-4o-mini) |

The server exposes a single `POST /api/generate` endpoint that returns `{ markdown, mode }`. The frontend is plain HTML/CSS/JS with a dependency-free Markdown renderer — no build step.

## Configuration

Copy `.env.example` to `.env` and set your key:

    OPENAI_API_KEY=sk-...
    PORT=3000

## API

`POST /api/generate`

    {
      "topic": "Why remote teams need async-first communication",
      "tone": "friendly",
      "toneLabel": "Friendly",
      "length": "medium",
      "lengthLabel": "Medium (~850 words)",
      "audience": "startup founders",
      "audienceLabel": "startup founders"
    }

Response:

    {
      "markdown": "# ...",
      "mode": "openai"
    }
